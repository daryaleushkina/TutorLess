# Только для Claude

Общие правила проекта — `AGENTS.md`. Здесь то, что делает один Claude:
допрос, холст claude.ai, слэш-команды и Workflow есть только у него.

- В ответах Даше — обращение по имени (Даша).
- **Допрос (`grilling`) — по умолчанию перед каждой новой задачей** и заново
  на каждую новую задачу в сессии. Без допроса — только короткий список:
  правка одной строки, переименование, починка красного теста, опечатка.
  Остальное, включая задачи, которые выглядят однозначными, но состоят из
  нескольких шагов, начинается с вопросов с рекомендуемым ответом и ценой
  ошибки; технические развилки — сводкой (`AGENTS.md`, «Формат работы»).
  Задание Codex — после подтверждения. Codex попросил повторный допрос — он
  только по его вопросу.
- Перед полным дизайном — живой каталог вариантов на холсте.
- **Задание на правку интерфейса и её проверка** — с четырьмя дизайнерскими
  скиллами разом: `impeccable`, `apple-design`, `emil-design-eng`,
  `ui-ux-pro-max`, в мини-аппе ещё `telegram-mini-app`. Не «выбрать
  подходящий»: каждый видит свою треть.
- **Проверка перед пушем** — и кода от Codex, и своего:
  - `/gp-review` вместе со встроенным `/code-review`; правка доступа (initData,
    права, платное, внешние хосты, OAuth) — ещё `/security-review`;
  - правка задевает интерфейс — ещё `interface-review`;
  - `/gp-explore` («злой пользователь») — после заметной фичи,
    `/click-path-audit` — перед релизом и после больших правок общего
    состояния; их находки — падающие сценарии в `e2e/_explore` (в git не
    попадают).
- ⚠️ **Агенты `gp-*` написаны под LifeCommit** (Worker, Supabase, `src/`):
  находки `/gp-review` сверять с кодом, а `/gp-explore` и `/click-path-audit`
  поднимают стенд, которого здесь нет, — до переписывания (#9) эти проверки
  делаются руками.
- Агенту ставить цель и зачем, а не только задачу; его ключевые утверждения —
  перепроверять, а не пересказывать.
- Рабочее дерево для задачи — рядом с основной папкой
  (`~/work/tutorless/greprepapp-<задача>`), а не в `.claude/worktrees` внутри
  неё: оттуда все скиллы попадают в контекст дважды.
- **Подписи в «Офисе Дарьи»** (приложение `~/work/munder-difflin`, Даша следит в нём
  за сессиями): сразу после запуска подписывать `~/bin/office-label` свою сессию —
  по роли, назначенной Дашей («Техлид», «Лид веба»…), каждого субагента
  (`claude:<agentId>`, «Ревьюер · доступ», «Дизайн · лендинг») и каждое задание
  Codex (`codex:<session-id>` из папки задания, по смыслу, без слова «Codex»).
  Без подписи там видно просто «claude»/«codex» (решение Даши 12.10.2026).
